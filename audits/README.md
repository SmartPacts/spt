# Reviews of this artifact

`SPT-review-2026-08.md` is an independent review of **exactly the two module hashes this
repository publishes**. It is redacted, and the redaction is described in the document itself.

## What this is, and what it is not

It is **not** a third-party engagement. No external firm has been paid to audit SPT. This review
was conducted internally, by a reviewer working from a cold context with no implementation
history — deliberately structured to be adversarial, but internal. Saying otherwise would
misrepresent the assurance level of a repository whose whole purpose is to *invite* outside
review.

It is also a **delta**: it reviews these bytes as a change over an immediately preceding version
that had itself been through a longer programme of reviews. Publishing it bare would imply a
narrower examination than actually happened, so the document opens by saying what came before.

## What we are asking for

An outside reviewer, on these exact bytes, before they hold anything. Everything you need is in
this repository: the source, the full suite, the gates, and `VERIFY.md`. If you find something,
`SECURITY.md` says how to reach us.
